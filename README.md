# LokiCheckout_Be

**This is an add-on package for adding some settings that feel good for the Belgium market. Note that it is not required. It
changes a couple of field labels and adds a grid layout `belgium_grid`. Both can also be defined in a custom project-specific module.**

## Installation
Install this package via composer (assuming you have setup the `composer.yireo.com` repository correctly already):
```bash
composer require loki-checkout/magento2-be
```

Next, enable this module:
```bash
bin/magento module:enable LokiCheckout_Be
```
